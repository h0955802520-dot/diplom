# БудМайстер — інтернет-магазин будівельних матеріалів

Дипломний проєкт. Інтернет-магазин будівельних матеріалів та інструменту з каталогом, кошиком, обраним, калькулятором матеріалів, особистим кабінетом та адмін-панеллю.

---

## Поточний статус

- ✅ **Фронтенд** — завершено (HTML/CSS/JS, без фреймворків)
- ⏳ **Доопрацювання фронту** — у процесі
- ⏳ **Бекенд** — попереду
- ⏳ **Деплой** — попереду

---

## Стек

### Зараз (фронт)
- HTML5 / CSS3 / Vanilla JavaScript
- Font Awesome 6.5
- localStorage для кошика, обраного, нещодавно переглянутих
- Зображення товарів — Unsplash CDN

### Бекенд (Python)
- **Python 3.12** — мова розробки бекенду
- **Django 5.x** — основний фреймворк (ORM, міграції, вбудована адмінка)
- **Django REST Framework (DRF)** — побудова REST API
- **PostgreSQL** — реляційна база даних
- **Simple JWT** — аутентифікація через JWT-токени
- **django-cors-headers** — CORS для зв'язку фронту та API
- **Pillow** — обробка зображень товарів
- **python-dotenv** — управління змінними середовища
- **gunicorn** — WSGI-сервер для продакшену
- **Docker + Docker Compose** — контейнеризація для локального запуску та деплою

### Деплой (запланований)
- **Фронт** → Vercel
- **Бек + БД** → Railway або Render
- Розділена архітектура (фронт окремо, API окремо)
- Vercel для бека (Django/Laravel) **не підходить** — потрібен постійний процес

## Що реалізовано на фронті

### Головна сторінка
- Top contact bar (телефон, графік, склади, безкоштовна доставка)
- Hero з 2 CTA кнопками
- Секція «Чому обирають нас» (6 карток з номерами)
- Категорії товарів (4 картки)
- Промо-баннери (3 у grid)
- Хіти продажів / Новинки / Акційні товари
- **Калькулятор матеріалів** (стіна / стяжка / фарбування / плитка)
- Нещодавно переглянуті (показуються тільки якщо є)
- Сітка брендів (10 кнопок-фільтрів)
- Блок «Про компанію»
- Блог (3 картки-заглушки)
- Відгуки клієнтів
- Підписка на новини (newsletter)
- Контакти + форма зв'язку

### Каталог (shop.html)
- 100 товарів у 7 категоріях: цемент, цегла/блоки, інструмент, фарби, метал, електрика, оздоблення
- Фільтри: категорія, тип робіт, бренд, фасування, діапазон цін, акції, хіти, обране
- Сортування: дешевше / дорожче / новинки / хіти
- Пагінація по 12 шт
- URL-параметри: `?wish=1`, `?promo=1`, `?popular=1`, `?sort=new`, `?brand=...`, `?type=...`
- Лічильник «Знайдено: N товарів»

### Картка товару (везде)
- Бейджи: ЗНИЖКА / ХІТ / НОВИНКА
- Кнопка ❤ (обране) — з localStorage
- Індикатор складу (зелений / помаранчевий / червоний)
- Кнопка «В кошик» disabled при stock = 0
- Lazy-loading зображень

### Сторінка товару (product.html)
- Хлібні крошки
- Велике фото
- Бренд, наявність, ціна (з old-price якщо акція)
- Лічильник кількості (+/-)
- Кнопки «В кошик» та «В обране»
- Список послуг (доставка / гарантія / повернення / консультація)
- 3 таби: Опис / Характеристики / Доставка та оплата
- Блок «Схожі товари»

### Кошик (cart.html)
- Список товарів з лічильниками кількості
- 4 способи доставки з автоматичним розрахунком:
  - Самовивіз (безкоштовно)
  - Нова Пошта (~80 грн, безкоштовно від 5000)
  - Кур'єр Київ (350 грн, безкоштовно від 5000)
  - Вантажне авто (від 800 грн)
- Промокоди: `BUD10` (-10%), `BUD500` (-500 грн), `NEW2026` (-15%)
- Мінімальна сума замовлення 300 грн (з блокуванням кнопки)
- Зведення: товари / знижка / доставка / разом

### Загальне
- Живий пошук у шапці (dropdown із фото та цінами)
- Toast-сповіщення при додаванні в кошик
- Маска телефону +380
- Кнопка «Вгору»
- Бургер-меню (мобільна версія)
- Адаптивність

## Дизайн-система

### Палітра (CSS-змінні в `:root`)
```css
--primary:      #f59e0b   /* амбер — основний акцент */
--primary-dark: #d97706
--accent:       #ea580c   /* помаранчевий — ціни, бейджі */
--dark:         #1e293b   /* темна сталь — шапка, футер */
--dark-2:       #334155
--steel:        #475569
--light-bg:     #f8fafc
--soft:         #fef3c7   /* блідо-жовтий — підкладки */
--border:       #e2e8f0
--text:         #1f2937
--muted:        #64748b
```

### Стилістика
- Індустріальна (сталь + амбер + помаранчевий)
- Uppercase заголовки з підкресленням-акцентом
- Border-radius 6-8px (без надмірного скруглення)
- Тіні стримані, hover-ефекти з translateY

## Дані (localStorage ключі)

- `budMasterCart` — масив товарів у кошику
- `budMasterWishlist` — масив id товарів в обраному
- `budMasterRecent` — масив id нещодавно переглянутих (макс 8)
- `budMasterPromo` — застосований промокод

> Після переходу на бек ці дані будуть синхронізуватися з сервером для авторизованих користувачів.
